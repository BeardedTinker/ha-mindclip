# Security policy

## Supported versions

Security fixes are provided for the latest released version of MindClip for
Home Assistant.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Do not report security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting for this repository when it is
available. If that option is unavailable, contact the maintainer through their
GitHub profile before sharing technical details.

Include the affected integration and Home Assistant versions, the impact, and
minimal reproduction steps. Do not include SwitchBot API credentials, device
identifiers, recording titles, summaries, transcripts, or raw API responses.

You should receive an acknowledgement within seven days. Confirmed issues will
be assessed privately and fixed before public disclosure whenever practical.
