## What's changed

- New MindClip To-Dos are tracked in a native Home Assistant To-do list.
- The first refresh establishes a baseline, preventing existing items from flooding the list.
- Pending items persist through restarts until marked complete as a local acknowledgement.

Acknowledgement does not complete or modify the source To-Do in SwitchBot. Existing config entries need no reconfiguration; install the update and restart Home Assistant.
